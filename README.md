Crea un proyecto React usando Vite con una estructura mínima, sin código de ejemplo ni archivos de relleno.

Requisitos:

- No incluir contador.
- No incluir logos de React ni Vite.
- No incluir imágenes.
- No incluir archivos CSS (App.css, index.css) a menos que sean necesarios.
- No incluir carpeta assets.
- No incluir useState ni otros hooks de ejemplo.
- App.jsx debe devolver únicamente un componente vacío.
- main.jsx debe contener únicamente el código mínimo para renderizar React.
- Mantener únicamente los archivos indispensables para que la aplicación funcione.
- No agregar librerías adicionales.
- No agregar componentes, páginas, rutas ni ejemplos.
- No agregar comentarios en el código.
- Utilizar JavaScript (.jsx), no TypeScript.

La estructura final debe ser lo más minimalista posible, conservando únicamente React, ReactDOM y la configuración necesaria de Vite.
